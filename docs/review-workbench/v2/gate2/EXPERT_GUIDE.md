# 专家操作指南（Gate 2，一页）

材料由工程整理；本人无需编辑JSON、复制摘要/事件URL或运行CLI。当前所有法律适用、时效/过渡及权利结论均not-verified，三个ledger均为空。

1. 在对应PR阅读候选README的五组问题、sources具体官方出处、precheck缺口及固定文件清单；必要时打开只读上游固定blob。27／4／19文件和排除4／9／2320不可默默变更。官方来源元数据不是专业通过；支持/反例只是待核场景。
2. 核实事实→条文/版本→过渡→推理→结论/限制；每个检查项均保留。缺证可要求补正或拒绝，不能以not-applicable表达没审。要判不适用，应让准备者在每条相关矩阵加入有事实和引用的理由，再本人复核新head。
3. 待维护者先接受实际本人账号/角色与受控能力资质索引后，复制该候选expert-form四块短表：核对系统Scope/Group-ID；本人填写五组决定/具体理由/限制、总体专业决定/理由/限制/COI、真实Regulatory-As-Of。未实际核法的非通过意见可写not-verified；通过须实际日期与完整证据。不要填写模型日期、抓取日或未来日。
4. 确认PR当前head和附件后，在Files changed → Review changes选择 **Comment**，仅保留一个lexrouter-review-v2代码块，由本人提交。不要让AI代发、不要用普通评论代替。事件变更/撤销或附件变化会阻断复用；重新核对并提交新事件。
5. 专业事件经可信同步及新head CI后，维护者审权利、工程和剩余阻塞，另提交独立admission_decision事件；专业通过不会自动入库。本轮没有签署、归档、托管或合并。

公开只放经允许的摘要/索引，不放证件、真实卷宗、私信或受限材料。法律/许可/来源版本变化须暂停和复核。
