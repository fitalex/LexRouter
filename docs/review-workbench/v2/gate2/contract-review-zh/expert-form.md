# 四块本人专业短表（占位稿）

先读[五组预览](README.md)和[来源/缺口](sources.md)。下面系统预填Review-ID、全部Scope和五组ID；所有尖括号必须由本人真实填写。本稿不是可提交意见，不预填任何决定、COI或实际核法日期。

组决定：approved-scope／needs-changes／rejected／not-applicable；总体专业决定：approved-scope／needs-changes／rejected。每组写检查项ID、事实→条文→推理、支持/反例、补正和限制。未核的非通过意见可填Regulatory-As-Of: not-verified；通过须本人实际核法日期并满足全部证据门槛。not-applicable须逐行事实/引用理由，不表示没看过。
