# P1 法律专业复核交接包

对象为三个 A 类**提案**，材料预审不授予托管权。[固定记录](../../data/reviews/p1-handoff.json) 与[逐文件边界](README.md)共同限定复核对象。当前全部 `professional_status=not-performed`、`regulatory_currency.status=not-checked`、`as_of=null`，没有已核实法域、法规时效日期、专家结论或签署。AI 只整理任务、源材料位置和官方检索线索，不代行执业判断。

## 共同操作与留证要求（每个候选分别完成）

| 项目 | 专业人员应逐项执行 | 证据要求 |
| --- | --- | --- |
| C01 固定版本与范围 | 复核下列候选、commit、入口及拟用清单；记录实际审阅文件及 blob | 指向本交接记录和 manifest；排除项不得悄然进入复核批准范围；改版重审 |
| C02 法域与事实 | 确认 CN-Mainland 及案件/合同地点、主体、行业、行为时间、判断时点；识别港澳台/涉外分支 | 明确可用及排除场景、必要事实、缺失信息；来源声明不等于专家确认 |
| C03 官方法律文本 | 按候选表中的任务核实每一引用，查找官方发布机关、文号、条款、原文和来源 URL | 保存可访问定位、文本版本/哈希和允许保存的摘录，区分法条、司法解释、政策、行业规范和案例 |
| C04 法律时效 | 对每项核对公布/施行/修订/废止、替代文件、地方规则和过渡/溯及适用 | 留下事实时间→适用版本→过渡规则→结论链；抓取日、commit 日和模型截止日不能填作法规时效 |
| C05 引用真实性与支持性 | 查条号/名称/原文是否真实，引用是否支持具体结论，是否遗漏例外或冲突 | 每条“条款/事实→法律问题→官方条文/案例定位→适用推理→结论/限制”可追溯；不能仅检查字符串命中 |
| C06 风险与升级 | 使用独立合成/获授权脱敏场景检查下面高风险项、缺失事实、工具失效和旧法陷阱 | 记录输入条件、实际输出证据、错误影响、纠正建议；不直接采用上游真实合同或其测评用例；实际运行须另获授权 |
| C07 人工裁决 | 对效力、收费、期限、重大交易、数据出境等问题明确人类决定点 | 记录有条件通过/补正/不通过及范围，存在分歧另行复核，不由评分或免责声明替代 |
| C08 权利与用途 | 与许可审核人员确认本轮审核的精确文件、引用材料、拟用场景和排除项 | 法律专业适用复核与著作权/许可审核分轴留证，任何一轴未通过均不能正式托管 |
| C09 签署 | 由具备相应能力的人员自行填写真实身份、资质/专业经验、独立性、复核日期、意见、限制、实际时效核查基准及证据位置并签署 | 受控记录可含完整身份；公开 PR 仅提供经允许的脱敏索引/摘要，由 Human Maintainer 核实证据可访问性；本包不预填 |
| C10 不通过/更新 | 缺证则补证，法律错误则单独修正/缩范围后重审；根本不适用则保留拒绝/暂停原因 | 保留原版本和意见；仍在候选区，不解除其他七条阻塞；来源、许可或法规实质变化触发新审计；Human Maintainer 另审入库 PR |

官方入口以下均为**查找线索**，本轮未逐一访问核实最新文本、条号或时效，不把门户可访问当成法规复核完成：国家法律法规数据库 <https://flk.npc.gov.cn/>、中国人大网 <https://www.npc.gov.cn/>、中国政府网政策库 <https://www.gov.cn/zhengce/>、最高人民法院 <https://www.court.gov.cn/>、司法部 <https://www.moj.gov.cn/>、国家发展改革委 <https://www.ndrc.gov.cn/>、国家网信办 <https://www.cac.gov.cn/>、市场监管总局 <https://www.samr.gov.cn/>、国家知识产权局 <https://www.cnipa.gov.cn/>、人力资源社会保障部 <https://www.mohrss.gov.cn/>。行业收费规范可从中华全国律师协会 <https://www.acla.org.cn/> 及当地律协、司法行政机关查找，需区分规范层级。案例从人民法院案例库 <https://rmfyalk.court.gov.cn/>、裁判文书网 <https://wenshu.court.gov.cn/> 核对全文、案号、裁判时间、事实与裁判要旨；访问和复制权限另审。

5. **高风险合成场景**：违约金与实际损失基数不同；保证金与定金混用；OCR 将费率小数点漏读；同一合同包含劳动与技术成果；施工许可不全；检索服务离线；涉外条款进入国内工作流。
6. **必须人工决定**：有效性与可执行性、重大交易、行业资质、劳动保护、涉外适用、数据/反垄断问题和风险等级，禁止把 Word 成功生成当专业通过。

8. **不通过**：保留对应规则为待修正/排除；另提有权修改的范围修正 PR 和复核，不能从“MIT”或原 ready 状态跳过。
